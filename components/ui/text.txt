Desired behavior

  href: "/about-us/naac"

In other words:

DB URL exists
    ↓
use DB URL

DB URL is empty/null/undefined
    ↓
use existing hardcoded href


This needs to work recursively at any depth because defaultItems contains nested children.

Preferred implementation

I am considering adding an optional dbKey to each NavItem:

type NavItem = {
  label: string;
  href: string;
  dbKey?: keyof PageLinks;
  children?: NavItem[];
};


For example:

{
  label: "Overview",
  href: "/about-us/overview",
  dbKey: "overview",
}


and:

{
  label: "NAAC Accreditation",
  href: "/about-us/naac",
  dbKey: "naac_accreditation",
}


Then recursively transform the navigation:

function mapDatabaseLinks(
  items: NavItem[],
  dbData: PageLinks
): NavItem[] {
  return items.map((item) => {
    const dbUrl = item.dbKey ? dbData[item.dbKey] : "";

    return {
      ...item,
      href: dbUrl?.trim() ? dbUrl : item.href,
      children: item.children
        ? mapDatabaseLinks(item.children, dbData)
        : undefined,
    };
  });
}
